# Prompt log

The notable prompts used to build Drift, one file per prompt, in order. Each entry
gives the intent, the prompt (shortened where it was long, with personal details
removed), and what it produced. The build was done by pairing with an AI coding
agent, which is why this log exists.

| File                                      | Intent                                        |
| ----------------------------------------- | --------------------------------------------- |
| `01-kickoff.md`                           | The project brief and working rules           |
| `02-cron-fan-out-decision.md`             | Approve the design that fits the free tier    |
| `03-durable-object-and-continuous-run.md` | Approve the storage change and run to the end |
| `04-more-modes-and-buses.md`              | Extend to more modes and on demand buses      |
